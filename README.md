# 🔐 Text Encryption and Decryption App

A beginner-friendly **Python GUI app** built with **Tkinter** that allows users to **encrypt and decrypt text** using **Base64 encoding**.  
It provides password protection, a clean interface, and basic cryptographic operations for educational use.

---

## 🧰 Tech Stack

- **Python 3**
- **Tkinter** — GUI framework for creating the interface  
- **Base64** — For encoding and decoding text  
- **OS / Messagebox** — For file handling and alerts

---

## ⚙️ Features

- 🔒 **Encrypt Text** — Securely encode any text message  
- 🔓 **Decrypt Text** — Decode messages with a secret key  
- 🔑 **Password Protected** — Only decrypts if the correct key is entered  
- ♻️ **Reset Functionality** — Clears all text and password fields  
- 🪟 **Simple GUI** — Clean and user-friendly interface  

---
